# Portfolio de Kadiata Kaba

Portfolio statique multi-pages, prêt pour GitHub Pages.

## Publication

1. Ajoutez votre photo sous le nom `photo.jpg` dans ce dossier.
2. Ajoutez votre CV sous le nom `cv.pdf` dans ce dossier.
3. Remplacez `votre-email@example.com` dans `contact.html` par votre adresse e-mail.
4. Téléversez tout le contenu de ce dossier dans un dépôt GitHub puis activez **Settings → Pages → Deploy from a branch**.

Les liens des huit projets sont déjà intégrés.
